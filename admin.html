⚙️ Configurar a publicação (fazer uma vez só)

Para o botão Publicar funcionar, é preciso colar aqui uma “chave de acesso” do GitHub. Ela fica guardada só neste aparelho.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Token name, escreva korin
  3. Em Expiration, escolha No expiration
  4. Em Repository access, marque Only select repositories e escolha korinclub
  5. Em Permissions → Repository permissions, ache Contents e mude para Read and write
  6. Clique em Generate token, copie o código e cole abaixo
